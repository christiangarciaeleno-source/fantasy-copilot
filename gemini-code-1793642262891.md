# Fantasy Copilot Pro - Directrices de Desarrollo
- Stack: HTML5, Tailwind CSS (CDN), Vanilla JS modular, sin dependencias de Node/npm (Zero-Build).
- Target: PWA standalone optimizada para Google Pixel (Android Chrome, 120Hz, safe-areas).
- Backendless: LLMs en cliente usando fetch nativo contra Google AI Studio y Anthropic API.
- Reglas de juego: Movistar Fantasy MARCA (LaLiga). Puntos SofaScore/Mixto, obligación de saldo >= 0 el viernes.
- Modularidad: Mantener archivos independientes bajo 300 líneas para máxima mantenibilidad.
