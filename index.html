Copiar datos desde la web del Fantasy (favorito)
  1. Pulsa "Copiar código del favorito".
  2. En Chrome: abre cualquier página, menú ⋮ → ☆ guardar en favoritos, y luego ⋮ → Favoritos → mantén pulsado el favorito → Editar. Ponle el nombre FantasyCopiar y pega el código en la URL.
  3. Entra en la web del Fantasy con tu sesión, abre Plantilla, Alineación o Mercado, escribe FantasyCopiar en la barra de direcciones y toca el favorito que sale (con la estrella).
  4. Vuelve a esta app y pulsa "Pegar texto del Fantasy". Repite con cada pantalla.
Modo manual (sin API Key ni cuotas)
  1. Pulsa "Copiar prompt".
  2. Abre gemini.google.com (o claude.ai), sube tu captura y pega el prompt.
  3. Copia el JSON que responda y pégalo aquí abajo.
